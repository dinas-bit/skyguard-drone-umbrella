# Contributing to SkyGuard

We love your input! We want to make contributing to SkyGuard as easy and transparent as possible.

## Development Process

1. Fork the repo and create your branch from `main`
2. If you have added code, add tests
3. Ensure the test suite passes (`pytest`)
4. Make sure your code follows the project style
5. Issue a pull request!

## Pull Request Process

1. Update README.md with details of changes if applicable
2. Update docs/ if architecture changes
3. PRs require at least 1 review before merging
4. CI must pass (firmware build + vision tests)

## Code Style

- **C++ firmware**: Follow Google C++ Style Guide
- **Python vision**: Follow PEP 8, use type hints
- **Markdown docs**: Use ATX-style headers, 80-char lines

## Issues

We use GitHub Issues to track bugs and feature requests.
Before opening an issue, check if a similar one already exists.
